# ColorHunt iOS リリース完全ガイド

初リリース向けに「今日から審査提出まで」を1本にまとめたガイドです。
対象: iOS 16〜26 / 開発機は新しい MacBook（Apple Silicon）+ Xcode 26。

---

## 0. 全体ロードマップ（目安 2〜4週間）

| 週 | やること |
|---|---|
| 1 | 環境構築 → 現行コードのビルド → 実機(iPhone 11)で自己テスト |
| 2 | Apple Developer 登録 → アイコン/スクショ作成 → TestFlight で知人配信 |
| 3 | フィードバック修正 → App Store Connect 登載情報 → 審査提出 |
| 4 | 審査対応（通常1〜3日）→ リリース 🎉 |

---

## 1. 新しい Mac の環境構築

1. **Xcode 26** を App Store からインストール（初回起動で追加コンポーネント許可）
2. **JDK 17**（KMP 共有モジュール用）: `brew install temurin@17`
3. リポジトリを clone し、ルートで一度:
   ```bash
   ./gradlew :shared:embedAndSignAppleFrameworkForXcode || true
   ./gradlew :shared:compileKotlinIosArm64   # K/N ツールチェーン初回DL
   ```
4. Xcode プロジェクト（ColorHunt）を開き、以下を確認:
   - Minimum Deployments = **iOS 16.0**
   - Run Script（shared フレームワーク埋め込み）のパスが新環境の実パスか
   - Framework Search Paths が `shared/build/xcode-frameworks/...` を指すか
   - Info.plist: `NSPhotoLibraryUsageDescription` / `NSPhotoLibraryAddUsageDescription`
     / `NSCameraUsageDescription`（ハントカメラ）
   - Localizations: en / ja / ko / zh-Hans が登録済みか
5. **Xcode 26 でのモダン化（任意・推奨）**: iOS 26 実機/シミュレータでは
   システム部品が自動で Liquid Glass 化。独自ガラスは `#available(iOS 26)` で
   追加予定（コードは iOS 16 フォールバック前提で設計済み）

## 2. Apple Developer Program（$99/年）

1. https://developer.apple.com で Apple ID から登録（個人でOK・住所は公開されない）
2. Xcode → Settings → Accounts にサインイン
3. ターゲットの Signing & Capabilities → **Automatically manage signing** + 自分の Team
4. これで実機インストールと TestFlight/提出が可能に

## 3. テストチェックリスト

### 3.1 機能チェック（各リリース前に全項目）

**オンボーディング**
- [ ] 初回起動でオンボーディングが表示 →「はじめる」でタブへ
- [ ] 2回目以降は表示されない

**ハント**
- [ ] 写真を選ぶ → 全枚数が色分けされる（「解析中」が残らない）
- [ ] 自動で仕分け → 権限ダイアログ → 直近200枚が入る
- [ ] 同じ写真を再度選んでも重複しない
- [ ] フィルタchips / カラーコレクションのドットタップで絞り込み
- [ ] 長押し → 色の付け直し／ゴミ箱で全消去

**コラージュ**
- [ ] 全セルでタップ→そのセルのトリミングが開く（開閉スムーズ・見切れなし・パン/ピンチ/リセット）
- [ ] 長押しドラッグで任意のセル入替（他セルは動かない・ターゲット枠が出る）
- [ ] テンプレ11種（カテゴリ: すべて/トレンド/レトロ/ミニマル で絞り込み・選択中に枠）
- [ ] 4カット=縦ストリップ / デイログ・フィルムで日付スタンプが右下でなく左下に出る
- [ ] 日付スタンプのトグルON/OFFがプレビューと書き出しの両方に反映
- [ ] レイアウト / パレット5配置＋帯調整 / HEXチップ / 色相整列
- [ ] SNSサイズ 1:1・4:5・9:16・16:9 でプレビュー高さが揃う
- [ ] 保存 → スピナー → トースト → 写真アプリに存在
- [ ] 共有 → シートが開く（キャプションがペースト可能）
- [ ] 無料時に透かし表示 / （デバッグ解除で）Pro時に消える

**ハントカメラ（実機のみ）**
- [ ] 中央タブボタン/中央スロットのタップでカメラが開く（タブ左右2:2の対称）
- [ ] 上部ピルに ターゲット色→ライブ色＋HEX＋マッチメーター が出て中央は塞がれない
- [ ] 今日の色に近づくとアークが満ち、一致で「見つけた！」＋パーティクル＋シャッター発光
- [ ] レンズ 0.5×/1×/2× 切替（機種により0.5×非表示可）/ セルフィー反転
- [ ] フラッシュ OFF/自動/ON・タイマー3s/10s（カウントダウン・シャッターで中断）
- [ ] アスペクト 4:3/1:1/9:16 → マスク表示どおりに切り抜かれて保存
- [ ] タップでフォーカスリング＋露出、±ボタンで露出スライダー
- [ ] フレームモード: テンプレ選択→ガイド枠に1枚ずつ→4/4で「コラージュを作る」
      →コラージュにテンプレ適用済み＋撮影順で4枚が入っている
- [ ] 左下サムネのタップでカメラが閉じてハントタブに遷移

**今日の色**
- [ ] ホイールtaps/ドラッグ選択・ルーレットが回って停止
- [ ] この色をハントする → アニメ → ハントにフィルタ適用
- [ ] リマインドON → 時刻設定 → 翌日通知が届く（実機で前日仕込み）

**グリッド**
- [ ] ＋タイルで追加 / 長押しドラッグ並べ替え / 長押しメニューで削除

**マップ**
- [ ] 位置情報つき写真が写真バブルで表示 / 色フィルタで絞り込み
- [ ] ピンをタップ → 写真+HEX / 写真に保存 → ピン入り地図が保存される

**課金（StoreKit Configuration でローカルテスト → 実機Sandboxで再確認）**
- [ ] 購入 → 透かし消滅 / 復元 / アプリ再起動後も Pro 維持

**多言語**: 設定→ColorHunt→言語 で en/ko/zh-Hans に切替 → 全画面崩れなし

## 4. TestFlight（知人配信）

1. App Store Connect → My Apps → ＋ → New App（Bundle ID は Xcode と一致）
2. Xcode: Product → **Archive** → Distribute → **TestFlight & App Store**
3. App Store Connect → TestFlight タブ → ビルドが処理完了後:
   - **Internal Testing**: 自分（最大100人・審査なし・即配信）
   - **External Testing**: 知人のメール招待（最初の1回だけ軽い審査・最大1万人）
4. 知人は TestFlight アプリから招待コードでインストール
5. フィードバックは TestFlight のスクショコメント機能で回収可能

> 以後は Archive → Upload するだけで自動的にテスターへ新ビルドが届きます。

## 5. App Store 提出

**必要素材**
- アイコン 1024px（`iosApp/AppIcon/` 参照）
- スクリーンショット（**6.9" と 6.5"** が必須。iPhone 16 Pro Max / 15 Plus シミュレータで ⌘S）
  - 構成案（6枚・全ロケール共通画像＋ローカライズ見出しテキスト）:
    1. ハントカメラ・フレームモード「撮りながら、コラージュになる。」（一番の差別化）
    2. ハント「色で、写真が整う。」（コレクションカードが見える状態）
    3. コラージュ組写「HEXパレットで、組写を。」
    4. テンプレカテゴリ「4カットもデイログも、ワンタップ。」
    5. 今日の色「今日は何色をハントする？」
    6. カラーマップ「あなたの街が、パレットになる。」
- プロモテキスト/説明文/キーワード（ja/en/ko/zh、`docs/STORE_LISTING.md` を流用）
- サポートURL（GitHub Pages 等の1枚ページでOK）/ プライバシーポリシーURL

**App Privacy（申告）**
- 写真: アプリ機能のため・トラッキングなし／位置: 写真のメタデータのみ・収集なし
- 収集データ「なし」（すべて端末内処理）— 強い訴求点なので説明文にも書く

**In-App Purchase**
- App Store Connect → Features → In-App Purchases → **Non-Consumable**
  `com.souru.colorhunt.pro`（価格は下記ロードマップ）→ 審査提出時に添付

**審査の注意**
- 初回はリジェクトされがち: 「復元ボタンがある」「課金前に機能説明がある」
  （どちらも実装済み）/ デモ用に写真数枚のスクリーン録画を添付すると通りやすい

## 6. 収益化ロードマップ

**方針: 買い切り先行 → 実績が出たらサブスク併設**（写真ユーティリティは
買い切りの支持が厚く、初アプリはレビュー資産を貯めるのが最優先）

| フェーズ | 内容 | 価格目安 |
|---|---|---|
| v1.0 リリース | Pro 買い切り（透かし削除・全テンプレ/配置） | **¥800**（US$4.99） |
| ローンチ週 | 「リリース記念」で | ¥600（$3.99）→ 定価に戻す |
| v1.1〜 | Pro 特典追加: 新テンプレ月次追加・書き出し高解像度(2160px)・マップ書き出しの透かし削除 | 据え置き |
| 3ヶ月後〜 | DAU/継続が取れたら **ColorHunt+ サブスク**（月¥300/年¥1,800・クラウド同期/限定テンプレ）を併設。買い切りユーザーは優待 | |
| 継続 | 今日の色×季節イベント（桜/紅葉/クリスマス限定パレット）で無料側の話題化→Pro転換 | |

**グロースの核**: 書き出し画像の透かし＝無料ユーザーが広告塔。
SNSハッシュタグ（#colorhunt #色集め）をキャプション自動コピーで統一済み。
ローンチ時は自分のSNSで「今日の色チャレンジ」を仕掛けるのが最短です。
