# こよみ 壁紙（Monolith / 黒 × オレンジ）

「ドット」ウィジェットと合わせる、道具のようなミニマル壁紙。1440×3120（19.5:9）。

- 背景 #0B0B0B = 「ドット」ウィジェット(ダーク)の背景色。不透明(100%)にすると枠が消えます
- アイコン列とドックの後ろにグラファイトのスラブ。オレンジはランプ・ドックのハンドルなど最小限
- フォルダの位置(左列+上段)を強調
