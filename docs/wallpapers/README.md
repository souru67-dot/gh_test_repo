# こよみ 壁紙（黒 × オレンジ / LEDドット）

透過した「ドット」ウィジェットに合わせた、黒基調・オレンジ差し色の壁紙です。1440×3120（19.5:9）。

| ファイル | 内容 |
|---|---|
| `koyomi-dot-black-orange.png` | フォルダ位置(左列4つ+上段の2つ)の背後にオレンジのLEDをほんのり灯し、半透明フォルダにコントラストを付けた版 |
| `koyomi-dot-black-orange-plain.png` | 同じデザインでフォルダ用の灯りなし(アイコン配置を変えた場合用) |
| `preview.png` | ホーム画面に置いたときのイメージ(左: フォルダ版 / 右: プレーン版) |

おすすめ設定: 「ドット」ウィジェットはテーマ=ダーク、透明度 0〜30%。
