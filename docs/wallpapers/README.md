# こよみ 壁紙（黒 × オレンジ / Ember）

「ドット」ウィジェットと一体に見えるよう設計した、黒基調・オレンジ差し色の壁紙です。1440×3120（19.5:9）。

- 背景の黒は **#0B0B0B = ウィジェット(ダーク)の背景色と同じ**。ウィジェットを不透明(100%)にすると枠が消え、時計だけが浮かびます
- 左下から差し込むオレンジの光が、半透明フォルダ(左列+上段)に温かい色を透かしてコントラストを付けます
- ドックの位置に、オレンジのヘアライン付きのガラス調の棚

| ファイル | 内容 |
|---|---|
| `koyomi-ember-black.png` | フォルダ位置(左列+上段)に光を当てた版 |
| `koyomi-ember-black-plain.png` | 光を下の方に控えめにした版(アイコン配置を変えた場合用) |
| `preview.png` | ホーム画面のイメージ(左: 通常版 / 右: プレーン版) |

おすすめ設定: 「ドット」ウィジェット = テーマ「ダーク」・透明度 **100%(不透明)**。
