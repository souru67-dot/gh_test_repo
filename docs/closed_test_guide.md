# クローズドテスト テスター向け説明(下書き) / Closed Test Guide

Play Console のクローズドテストに参加いただくテスターへ配布する文面の下書き。

---

## テスターの皆さまへ

Lumina(撮る人のためのギャラリー)のクローズドテストにご協力ありがとうございます。
実機での使い勝手と不具合の洗い出しにご協力ください。

### 参加手順
1. 招待メール(または参加用リンク)から、テスト参加に「オプトイン」してください。
2. Google Play から Lumina をインストール(通常のアプリと同じ手順)。
3. 初回起動で写真・動画へのアクセスを許可してください。

### 特に見てほしい観点
- **一覧の快適さ**: 1万枚規模でもスクロールが滑らかか。ピンチでの列数変更が自然か。
- **ビューア**: 開閉のトランジション、下スワイプで閉じる操作、RAW⇔JPEG 切替。
- **編集**: 写真の調整の反応、長押しA/B比較、保存(元写真が上書きされず別名保存か)。
- **動画**: LUT 適用プレビュー、トリム、書き出し(通知の進捗、保存先)。
- **課金(重要)**: 「設定 → Proを購入」で購入 → 全 Pro 機能が解放されるか。
  アンインストール → 再インストール後に「購入を復元」または起動で復元されるか。
  ※ ライセンステスターは実際の課金は発生しません。
- **無料の使い心地**: 未購入でも主要フロー(閲覧・共有・削除・基本調整)が快適か。
  Pro の案内がしつこくないか。

### 不具合の報告方法
- 何か問題が起きたら、可能なら再現手順・端末名・OSバージョンを添えてご連絡ください。
- アプリがクラッシュした場合は「**設定 → 不具合を報告**」から、端末内のログ
  (`crash.txt`)を共有していただけると原因特定が早まります(自動送信はされません)。

### 既知の制限
- Pro の購入状態はサーバー検証を行わない端末内完結方式です(その分オフラインでも
  使えます)。
- 動画の書き出しは端末性能に依存して時間がかかることがあります。
