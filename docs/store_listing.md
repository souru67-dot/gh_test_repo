## 日本語

### アプリ名
Lumina — 撮る人のギャラリー

### 短い説明(80文字以内)
RAW+JPEGを賢く扱う、写真好きのためのミニマルなギャラリー。LUT・投稿プレビュー・Lightroom連携。端末内完結で安心。

### 詳しい説明
Lumina は「撮る人」のために作った、黒基調でミニマルなギャラリーです。写真が主役。

**撮影者に寄り添う閲覧**
- RAW+JPEG を自動でペアリングし、1枚として整理。ビューアで RAW⇔JPEG を同じ構図のまま切替
- すべて / 写真のみ / 動画のみ、JPEG / RAW の絞り込み
- 日付グルーピングのグリッド、ピンチで列数変更(2〜5列を滑らかに)、高速日付スクラバー
- 撮影情報(EXIF)の表示、お気に入り、ゴミ箱(復元可)、アルバム
- USB/SDカードの写真・動画も SAF で閲覧・取り込み

**そのまま仕上げる編集**
- 写真の基本調整(露出・コントラスト・色温度など11項目)を GPU でリアルタイム、保存は常に別名(非破壊)
- 動画に 3D LUT(.cube)をリアルタイム適用、トリム、簡易調整、SNS向けの安全な書き出し
- 入力変換: 各社の Log 素材を Rec.709 に正規化してから同じプリセットを適用。
  Sony S-Log3 / Apple Log は公開仕様の数式で対応、HLG はトーンマップで対応。
  DJI・各スマホの Log は近似対応(アプリ内で「近似」と明示)
- 自前で数学生成した LUT プリセット(実在ブランド名は不使用)
- Lightroom Mobile 連携で RAW をそのまま現像へ

**投稿前に確認**
- Instagram のグリッド/フィード/リールでの見え方を投稿前にプレビュー

**プライバシー**
- 完全に端末内で完結。写真や位置情報をサーバーへ送信しません(ネットワーク権限なし)

**無料 + Pro(買い切り)**
無料でも本格的なギャラリーとして完結。Pro は買い切りで、全LUT・.cube取り込み・
投稿プレビュー・SNSセーフ書き出し・動画フレーム書き出し・位置情報除去共有を
アンロックします。

## English

### App name
Lumina — A Gallery for Photographers

### Short description (max 80 chars)
A minimal gallery for photographers. RAW+JPEG pairing, LUTs, post preview, Lightroom. Fully on-device.

### Full description
Lumina is a minimal, black-first gallery built for people who shoot. Your photos take center stage.

**Browsing made for shooters**
- Automatic RAW+JPEG pairing, organized as one item; switch RAW⇔JPEG in the viewer with the same framing
- Filter by All / Photos / Videos and JPEG / RAW
- Date-grouped grid, pinch to change columns (2–5, smoothly), fast date scrubber
- EXIF info, Favorites, Trash (restorable), Albums
- Browse and import from USB/SD cards via SAF

**Finish without leaving**
- Real-time GPU photo adjustments (11 controls); saves are always non-destructive copies
- Apply 3D LUTs (.cube) to video in real time, trim, quick adjustments, SNS-safe export
- Input transform: normalize Log footage to Rec.709 before applying the same preset.
  Sony S-Log3 / Apple Log use published-spec math; HLG is handled via tone mapping.
  DJI and phone-maker Logs are approximate (labeled "approx." in-app)
- Mathematically self-generated LUT presets (no real-world brand names)
- Send RAW straight to Lightroom Mobile

**Check before you post**
- Preview how it looks in an Instagram grid, feed, and reel before posting

**Privacy**
- Fully on-device. Your photos and location are never sent to any server (no network permission).

**Free + Pro (one-time purchase)**
Complete as a serious gallery for free. Pro is a one-time purchase that unlocks all LUTs,
.cube import, post preview, SNS-safe export, video frame export, and location-stripped sharing.
