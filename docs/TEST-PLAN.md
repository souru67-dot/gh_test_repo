# こよみ リリース判定テストプラン

**判定基準: P0 が全件パス、P1 に致命的な不具合なし → リリース可。**
P2 は余裕があれば。落ちた項目は必ず「手順・期待・実際・スクショ」をメモして修正へ。

- 推奨環境: 実機2台(Android 13以上 + できれば Android 10〜12 の古め1台)
- 各セットを **ライト/ダーク両テーマ** で一巡するのが理想。最低限、T15-1〜3 で両テーマを確認
- 課金テストは **デバッグAPKのプレミアム切替** で先に全ゲートを確認し、
  内部テスト版で **実購入(ライセンステスター)** を最後に1回通す

---

## T1. 初回起動・権限 (P0)

| # | 手順 | 期待 |
|---|---|---|
| 1-1 | クリーンインストール→起動 | オンボーディング表示。「アクセスを許可」→権限ダイアログ→月表示へ |
| 1-2 | 権限を**拒否**して進む | クラッシュせず、月表示に「カレンダーへのアクセスが…」バナー+設定導線 |
| 1-3 | バナーから権限を後付け許可 | 予定が表示される |
| 1-4 | Googleアカウント未設定の端末(または全カレンダー非表示) | 「カレンダーアカウントが見つかりません」案内。クラッシュなし |

## T2. 月表示・ナビゲーション (P0)

| # | 手順 | 期待 |
|---|---|---|
| 2-1 | 左右スワイプで前後の月へ 12ヶ月分 | 表示崩れ・重複なし。ヘッダーの年月が追従 |
| 2-2 | 「今日」ボタン | 当月に戻り今日が選択される |
| 2-3 | ヘッダーの年月タップ→年月ジャンプ | 指定月に移動 |
| 2-4 | 表示切替→年表示→任意の月をタップ | 月表示がその月にジャンプ |
| 2-5 | 設定「縦方向に連続スクロール」ON | 縦スクロールでも 2-1〜2-3 が成立 |
| 2-6 | 日セルをタップ | 下のシートがその日に切替(即時) |
| 2-7 | 日セルを**ダブルタップ** | 新規予定エディタが開く(日付=その日) |
| 2-8 | 週の開始を月曜に変更 | 月グリッド・年表示・ウィジェットすべて月曜始まりに |

## T3. 予定の作成・編集・同期 (P0)

| # | 手順 | 期待 |
|---|---|---|
| 3-1 | 時間指定の予定を作成(場所・メモ・色・通知10分前) | 保存後、月とシートに表示。**設定した「新規予定のカレンダー」が初期選択されている** |
| 3-2 | 終日予定を作成 | 「終日」表示。日付ズレなし(前日/翌日にならない) |
| 3-3 | 複数日にまたがる予定を作成 | 帯(バー)で連続表示。週を跨いでも切れ目が正しい |
| 3-4 | 毎週の繰り返し予定を作成→1回分だけ編集→「この予定のみ」 | その回だけ変わり、他の回は元のまま |
| 3-5 | 繰り返し予定を「すべての予定」で削除 | 全回消える |
| 3-6 | アプリで作成→**Web版Googleカレンダー**で確認 | 数分内に反映(タイトル・時刻・色) |
| 3-7 | Web版で予定を追加・変更→アプリへ戻る | 同期で反映される(手動で開き直してOK) |
| 3-8 | 予定詳細の**場所をタップ** | Googleマップ(または地図アプリ)が開く |
| 3-9 | 予定の色を変更 | アプリとWeb版の両方に反映 |

| 4-2 | 通知タップ | アプリがその日を開く |
| 4-3 | 画面OFF(Doze相当)で 4-1 を再確認 | 多少遅延しても1回だけ |

| 4-5 | 通知権限OFF時 | 設定画面に「無効」表示と許可導線。クラッシュなし |

## T16. 国際化(海外展開する場合) (P1)

端末の言語・地域を切り替えて確認する。設定 → システム → 言語で切替。

| # | 手順 | 期待 |
|---|---|---|
| 16-1 | 端末言語を英語にして起動 | UIが英語。日付・曜日が英語表記。崩れ・文字あふれなし |
| 16-2 | 端末言語を簡体字中国語 / 繁体字中国語 / 韓国語に切替 | 各言語でUIが表示される(未訳の英語混在がない)。**繁体字は台湾用語(活動・行事曆)** |
| 16-3 | 端末の時刻を**12時間表示**に設定(米国ロケール等) | 予定・ToDo・通知・ウィジェット・時計ウィジェットの時刻が **AM/PM 表記**になる |
| 16-4 | 端末を**24時間表示**に設定 | 時刻が **HH:mm** 表記になる |
| 16-5 | 設定「祝日」→ アメリカ | 7/4(Independence Day)や11月第4木曜(Thanksgiving)が赤+祝日名。週末に当たる固定祝日に (observed) が付く |
| 16-6 | 設定「祝日」→ イギリス | Good Friday / Easter Monday / bank holiday が表示(イースターは年で移動する) |
| 16-7 | 設定「祝日」→ 韓国 | 固定祝日+旧正月(설날)・秋夕(추석)が3日、仏誕が表示。**注**: 政府告示の振替休日は出ない前提 |
| 16-8 | 設定「祝日」→ 端末の地域に合わせる | 端末リージョンがJP→日本、US→米国等に自動追従。未対応地域は「表示しない」相当 |
| 16-9 | 設定「祝日」→ 表示しない | 日曜のみ赤、祝日ハイライトなし |
| 16-10 | 天気の地点検索を英語/中国語端末で実行 | 地名候補が端末言語で返る(日本語固定ではない) |
| 16-11 | 各言語でウィジェットを設置 | ウィジェット内テキストも翻訳される |
| 16-12 | (中東を狙う場合のみ)アラビア語に設定 | 未対応。RTL反転は現状しない ⇒ 対象にするなら別途対応が必要 |

**海外展開の判定**: 16-1〜16-4・16-10・16-11 がP1。祝日(16-5〜16-9)は進出先の国だけ確認すれば可。

# Playストア リリース作業チェックリスト

## A. ビルド・署名
- [ ] `keystore/release.keystore` を生成しローカル保管(docs/RELEASE.md 手順)。**紛失=更新不能なので2箇所にバックアップ**
- [ ] versionCode=1 / versionName=1.0.0 を確認(以後リリース毎に versionCode+1)
- [ ] 署名付きAAB をビルド(またはCIの `koyomi-release-aab` を使用し Play App Signing に委任)

## B. Play Console 初期設定
- [ ] デベロッパー登録($25)・本人確認
- [ ] アプリ作成(日本語、無料アプリ+アプリ内購入)
- [ ] **アプリ内アイテム**: 商品ID `premium_unlock`(管理対象・非消費型)、名前「こよみ プレミアム」、価格設定→**有効化**
- [ ] 設定→ライセンステストに自分のGmailを追加

## C. ストア掲載(docs/store-listing.md を元に)
- [ ] アプリ名・短い説明・詳しい説明
- [ ] アイコン512px(docs/icon-master.svg から書き出し)
- [ ] フィーチャーグラフィック 1024×500
- [ ] スクリーンショット 最低4枚(推奨8枚: 月表示/和の暦/日別シート/年表示/ウィジェット/きせかえ/ToDo/プレミアム)
- [ ] **プライバシーポリシーURL**(docs/privacy-policy.ja.md をGitHub Pages等で公開)
- [ ] (海外展開する場合)対象言語ごとの**ローカライズ掲載情報**(英・簡体中・繁体中・韓)とスクリーンショット。掲載言語を追加しないと、アプリが翻訳済みでもストアは英語のまま表示される

## D. 申告フォーム
- [ ] データセーフティ(docs/data-safety.md が回答下書き: カレンダーは端末内処理、天気は座標のみ送信、収集なし)
- [ ] コンテンツレーティングのアンケート(全年齢)
- [ ] 広告なし申告、対象年齢、ニュースアプリでない等の申告

## E. テスト→公開
- [ ] **内部テスト**トラックにAABをアップロード→本テストプランのT14を実施
- [ ] (推奨)クローズドテストで数日、家族・友人数名に使ってもらう
- [ ] 製品版に昇格→**段階的公開(20%→50%→100%)** を推奨
- [ ] 審査提出(初回は数日かかることあり)

## F. 公開後の初週
- [ ] Play Console「Android vitals」でクラッシュ率・ANR率を毎日確認
- [ ] レビューへの返信(特に不具合報告は最優先)
- [ ] 課金の注文管理で購入・返金を確認
