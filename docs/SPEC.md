# こよみ (Koyomi) — アプリ仕様書

_最終更新: 2026年7月16日 / ブランチ: `claude/koyomi-v2`_

「端末のカレンダーを、そのまま。墨と和紙の静かな画面で。」
月表示に特化した、日本の暦文化に寄り添うミニマルなAndroidカレンダー。広告・
解析・トラッキングなし、買い切りを想定。

---

## 1. コンセプト
- **月表示が主役**。常時開くボトムシートで片手操作。
- **和の世界観**(墨・和紙・朱)を基調にした独自ビジュアル。
- **端末のカレンダーをそのまま読み書き**(Googleカレンダー等)。独自サーバー・
  独自アカウントなし。予定は端末とユーザー既存アカウントの中にとどまる。
- **日本の暦文化**(祝日・六曜・二十四節気・旧暦・月齢・和暦)を、競合が持たない
  差別化点として搭載。すべて設定でON/OFF、既定はOFFかごく控えめ。

## 2. 技術スタック
- Kotlin / Jetpack Compose + Material 3(Dynamic Color 任意)
- MVVM + StateFlow、単方向データフロー
- 予定の実体は **CalendarProvider**(端末カレンダー)。設定は DataStore、
  タスク・テンプレートはローカル SQLite。
- ウィジェットは Glance、バックグラウンドは WorkManager
- minSdk 26 / targetSdk 35 / compileSdk 35、JDK 17
- 手動DI(`AppContainer`)

## 3. 画面構成
| 画面 | 役割 |
|---|---|
| 月表示(ホーム) | 6週グリッド + 常時ボトムシート。祝日/暦情報/予定/タスク表示 |
| 日別シート | 選択日の予定・タスク、暦ラベル、予定詳細(編集/複製/複数日複製/テンプレ保存/削除) |
| 予定/タスク編集 | 予定・タスクをタブ切替。日時・繰り返し・通知・色・カレンダー |
| 検索+アジェンダ | キーワード横断検索。空欄時は「これからの予定」を**約1年先**まで一覧 |
| 週/日タイムライン | 週・日の時間軸表示 |
| 設定 | 週開始・スクロール・テーマ・暦表示・同期・通知・ウィジェット・カレンダー表示・データ入出力 |
| オンボーディング | 初回のカレンダー権限付与 |

## 4. カレンダー連携(CalendarProvider)
- Instances 照会(`VISIBLE=1 AND DELETED=0 AND STATUS != CANCELED`)で
  削除済み・キャンセル済みを除外。
- 予定色は `DISPLAY_COLOR`(未設定時はカレンダー色にフォールバック)。Google
  ユーザー設定色(Colorsテーブルのパレット)にも対応。
- 予定の作成/編集/移動/複製/削除、繰り返し(FREQ/BYDAY/UNTILの部分対応、
  それ以外はCUSTOMとして原文保持)、単発の例外編集/削除、通知(Reminders)。
- 読み取り専用カレンダー(購読・祝日等、`CALENDAR_ACCESS_LEVEL < CONTRIBUTOR`)は
  表示ON/OFFのみ。予定作成先には選べない。
- 手動同期要求(`requestSync`)+ 定期同期(WorkManager、間隔設定可)。

## 5. 月表示
- 6週固定グリッド。今日=塗り円、選択=角丸ワッシュ。
- 連日予定は帯(最大2レーン、線の上に中央寄せタイトル)、当日予定は左ノッチ色チップ。
- **タスクもチップ表示**(☑/☐マーカー+タイトル、完了は打ち消し線)。
- あふれは「予定+タスク」合算の「+N」に集約。
- 横スワイプ(ページャ)/縦連続スクロールを設定で切替。
- 左上「年月」タップで**年月ジャンプ**(▼)。和暦表示にも切替可。
- 週番号(ISO)の左レール表示(任意)。

## 6. 日本の暦文化(差別化の核)
天文計算エンジン `Kyureki`(朔=新月、太陽黄経、1900–2099年)で算出。
| 機能 | 表示場所 | 既定 |
|---|---|---|
| 祝日・振替休日・国民の休日 | 月グリッド(赤日)・日別シート | 常時 |
| 六曜(大安・仏滅…) | 月グリッド各日の副行・日別シート | OFF |
| **二十四節気**(立春・夏至…) | 月グリッド副行(朱)・日別シート | OFF |
| **旧暦の日付**(神無月十五日) | 日別シート | OFF |
| **月齢・月相**(月齢14.2・満月) | 日別シート | OFF |
| **和暦**(令和8年) | 月ヘッダーの年 | OFF |
- 副行は固定高スロットで、節気が稀でも帯・チップの整列を維持。節気は六曜より優先。

## 7. タスク
- 予定と独立したローカルタスク(SQLite)。日付・任意時刻・色・通知に対応。
- 通知は WorkManager の遅延ワンショット(再起動耐性、exact-alarm権限不要)。
- 月グリッドにチップ表示、日別シートでチェック切替・編集・削除。

## 8. 予定の操作
- **編集 / 複製(日付選択)/ 削除**(繰り返しは範囲選択)。
- **複数日への一括複製**: ミニ月カレンダーで複数日を選び、まとめて複製。
  完了スナックバー+「元に戻す」(作成分を全削除)。
- **予定テンプレート**: 既存予定から「テンプレート保存」→ 日別シートの
  「テンプレートから追加」で選択日にワンタップ作成。
- ドラッグ&ドロップ移動は一度実装したがユーザー方針により見送り(ロールバック済み)。

## 9. テーマ / 外観
- ブランドパレット「墨・和紙・朱」。
- **きせかえテーマ**5種: 墨と和紙 / 桜 / 若葉 / 藍 / 紅葉(ライト/ダーク対応)。
- Material You(Dynamic Color)は任意(既定OFF)。テーマ/ライト/ダーク/システム。
- 曜日・祝日色はテーマ非依存で可読性を確保(日=朱系、土=藍系)。

## 10. 検索 / アジェンダ
- タイトル・場所・メモを横断検索(過去1年〜先2年、非表示カレンダー除外、
  250msデバウンス)。
- 空クエリ時は「これからの予定」を**約13ヶ月**先まで日付見出し付きで一覧
  (自分が登録した予定をタイトル込みで見返せる)。

## 11. ウィジェット(Glance)
| 種類 | 内容 |
|---|---|
| 月カレンダー | 予定をカレンダー色で表示。レスポンシブ |
| 今日の予定 | 今日/明日の予定を時刻付き |
| 時計+今日の予定 | 時計と直近3日の予定 |
| カレンダー+今日 | 月カレンダー下に今日の予定 |
| 今日+ミニカレンダー(4×2) | 左=今日の予定、右=当月のみのミニ月(予定日にドット、月見出し付き) |
- **どこをタップしてもアプリ起動**(ルートに clickable、子要素のタップを優先)。
- 予定・タスクの変更時に自動更新。テーマ/透明度を個別設定可(設定画面の設定)。

## 12. 通知
- 予定リマインダー(CalendarProvider の Reminders + `EVENT_REMINDER` 受信)。
- タスクリマインダー(WorkManager)。
- Android 13+ は設定から通知権限を要求。

## 13. データ入出力
- **ICS エクスポート/インポート**(RFC 5545 準拠の自前実装: TZID/終日/繰り返し/
  エスケープ/行折返し)。書き出し=表示中カレンダー、取り込み=書込先を選択。
- 端末外への独自送信は一切なし。

## 14. プライバシー / バックアップ
- 収集・送信・共有なし。広告・解析・第三者SDKなし。権限はカレンダーと通知のみ。
- Android バックアップ対象は**設定のみ**(カレンダーデータはアプリに保存しない)。
- ポリシー: `docs/privacy-policy.md`(日英)。

## 15. リリース準備(フェーズ4済み)
