# ColorHunt — Instagram リール構成台本 v1.0

対象: App Store リリース時のアプリ紹介リール
尺: **24.0秒** / 9:16 / 1080×1920 / 30fps / 7カット

> 再生できる絵コンテ（尺とテロップのタイミング確認用）は Artifact 版があります。
> このファイルが文言と尺の正となります。

## 構成の考え方

- **フックは「フレームモード」に置く。** 一番目新しく、かつ1秒で理解できるのがこれ。
  自動仕分けは説明が要るので後段に回します
- **完成物を序盤（5秒地点）で見せる。** 「で、何ができるの？」を早く解消するほど
  離脱が減ります
- **無料機能だけで構成する。** Pro テンプレはカット5の棚に映り込む程度に留め、
  「課金しないと何もできない」印象を作らない

### カット1 — フレームモードで1枚目（0.0–2.0s・HOOK）

- **撮影**: ハントカメラを開き、フレーム棚から「2×2」を選択。被写体に向けて
  シャッター。枠の左上マスに写真が入る瞬間まで
- **テロップ**: 撮った瞬間、コラージュになる。
- **演出**: 最初の0.5秒で枠が見えていること。ここで指を動かさない。
  シャッターで0.2秒だけ白フラッシュを入れる

### カット2 — 残り3枚を連続で撮る（2.0–5.0s）

- **撮影**: 2〜4枚目を続けて撮影。マスが順に埋まっていく。等速で撮っておき、
  編集で1.5〜2倍速
- **テロップ**: なし
- **演出**: シャッター音をビートに合わせる。**リールの心臓部**です

### カット3 — 完成したコラージュ（5.0–8.0s）

- **撮影**: コラージュ画面へ自動遷移した状態。HEXパレットが見えるまで待って1秒静止
- **テロップ**: HEXパレット付きで、そのまま書き出し。
- **演出**: ここは動かさない。完成形をしっかり見せる唯一のカット

### カット4 — カメラロールを色で仕分け（8.0–12.0s）

- **撮影**: ハントタブ →「自動で仕分け」→ トースト表示 → 色グループが並ぶまで
  スクロール
- **テロップ**: カメラロール200枚が、12色に。
- **演出**: スクロールはゆっくり一定速度で。速いと何も読めません

### カット5 — テンプレート12種（12.0–16.0s）

- **撮影**: コラージュのテンプレ棚をカテゴリ順に横スワイプ。
  トレンド → レトロ → ミニマル
- **テロップ**: テンプレートは、12種類。
- **演出**: 1カテゴリ約1.3秒。指はゆっくり、カードが読める速度で

### カット6 — 今日の色（16.0–19.5s）

- **撮影**: 今日の色タブでルーレットを回し、止まるまで。決まった色のカードが
  出たところでカット
- **テロップ**: 今日の色を、街でハントしよう。
- **演出**: 回り始めから止まるまでを1テイクで。途中でカットしない

### カット7 — ロゴ + CTA（19.5–24.0s）

- **撮影**: 画面収録は不要。アイコンとワードマークの静止カード
- **テロップ**: ColorHunt / 世界を、色で集めよう。/ App Store で配信中
- **演出**: 最後の1秒はロゴだけ。プロフィールに飛ばす導線をここで置く

## 収録のしかた

- iPhone の**画面収録**（設定 › コントロールセンターで追加）。マイクはオフ
- 収録前に**おやすみモード**。通知バナーが1枚でも映ると撮り直しです
- ハントには**見栄えする写真だけ**を先に入れておく。スクショや暗い写真は事前に消す
- 各カットは**指定尺の2倍**回す。編集で頭とケツを切る余白が要ります
- 指は画面の**端から**入れる。中央から出てくると不自然です
- バッテリー表示・時刻が映るので、**充電100%・きりの良い時刻**だと画面が締まります

## 編集（CapCut 想定）

- プロジェクトは `9:16` / `1080×1920` / `30fps`
- カットの切り替えは**必ずビートの頭**に置く。ここだけで完成度が変わります
- テロップは**画面下から22%より上**。下は Instagram のUIバーで隠れます
- トランジションは使わない。**ストレートカット**のほうが速く見えます
- 書き出しは `1080p / 30fps / 高画質`

## 音

- Instagram の**アプリ内音源**から選ぶ（外部音源は権利判定でミュートされる場合あり）
- 「保存数が伸びている音源」を優先。再生数より保存数が効きます
- シャッター音は**消さない**。カット2の連写がリズムになります

### 導線（投稿前に準備すること）

**リールにリンクは貼れません。** 順番を守らないと機能しません。

1. **プロフィールのリンクに公開リンクを設定**（投稿前に必ず）
2. **投稿直後に1つ目のコメントを自分で書いて固定**

```
参加方法📱
1. App Storeで「TestFlight」を入れる（無料・Apple公式）
2. プロフィールのリンクをタップ
3. 「Install」でインストール

不具合や気になったことは、TestFlightアプリから
スクショ付きで送れます🙏
```

3. **リールをストーリーズにシェアして、リンクスタンプを重ねる** ← 本命

**クリックできるのはストーリーズだけ**です。リールで見つけてもらい、
ストーリーズで踏んでもらう二段構えにします。
