# ColorHunt で学ぶ Swift / SwiftUI

**このシリーズの方針: 一般的な入門書は書きません。**

例文はすべて、あなたのアプリ `ColorHunt` の実際のコードから採っています。
読んだその足で Xcode を開き、同じ行を自分の目で確認できます。
「動いているアプリの中身が分かる」ことが、初心者にとって一番の近道だからです。

## 読み方のコツ

### 1. 必ず Xcode を開いたまま読む

各セクションには `AppState.swift:48` のようにファイル名と行番号を書いています。
Xcode で **⌘⇧O**（Open Quickly）を押してファイル名を打つと、すぐ飛べます。

**読むだけでは身につきません。** 実際のコードを目で追ってください。

### 2. 分からない記号は飛ばしていい

Swift には記号が多く、最初は全部気になります。ですが、
**アプリを理解するのに必要な文法は、実は全体の2割程度**です。
このシリーズはその2割に絞っています。出てこない文法は、当面知らなくて構いません。

### 3. 「なぜこう書くのか」を重視する

文法だけ分かっても、コードは書けるようになりません。
各所に「**なぜこうしたか**」を書いています。そちらが本体だと思ってください。

### 4. 壊してみる

一番学べるのは、**わざと壊して、エラーを読むこと**です。
`git` で管理されているので、いくら壊しても `git checkout .` で元に戻せます。

```bash
# 変更を全部捨てて元に戻す
git checkout .
```

安心して壊してください。

## ColorHunt の全体像（1分で）

詳細は [04-architecture.md](04-architecture.md) にありますが、先に地図を渡します。

```
┌──────────────────────────────────────────────┐
│  画面（SwiftUI View）                         │
│  HuntView / CollageView / HuntCameraView …   │
│  「何を表示するか」だけを書く                  │
└────────────────┬─────────────────────────────┘
                 │ 状態を読む / 操作を伝える
┌────────────────▼─────────────────────────────┐
│  AppState（唯一の司令塔）                     │
│  写真・選択・今日の色・Pro状態                 │
│  すべての画面がここを見ている                  │
└────────────────┬─────────────────────────────┘
                 │ 色の判定・コラージュの配置計算
┌────────────────▼─────────────────────────────┐
│  SharedColor（Kotlin で書かれた共通部品）      │
│  Android版とまったく同じ計算をする              │
└──────────────────────────────────────────────┘
```

**覚えることは1つだけです: 画面は `AppState` を見て、`AppState` だけがデータを持つ。**

ファイルの大きさは目安になります。

| ファイル | 行数 | 役割 |
|---|---|---|
| `CollageView.swift` | 1625 | コラージュ画面（一番複雑） |
| `HuntCameraView.swift` | 1546 | カメラ画面 |
| `AppState.swift` | 796 | 司令塔 |
| `HuntView.swift` | 389 | ハント画面 |
| `TodayColorView.swift` | 370 | 今日の色 |
| `HuntMapView.swift` | 336 | カラーマップ |
| `ColorHuntApp.swift` | 329 | 起動・タブ・オンボーディング |
| `GridPreviewView.swift` | 174 | グリッド |

**最初に読むなら `HuntView.swift`（389行）**です。一番素直な作りをしています。
