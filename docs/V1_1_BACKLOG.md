## あなたから届いたもの

### 1. ✨ HEXチップの値を自分で編集できるようにする

> 2026-08-04 受領

コラージュの HEXチップ（写真の左下に出る色ドット＋HEX）と、カラーパレット（採集票）に
印字される色を、自動判定に任せきりではなく**自分で決められる**ようにする。

**なぜ効くか**: このアプリの書き出し画像で、いちばん「作品」らしさを出しているのが
HEX の印字です。そこが1つでも意図と違う色だと、作品全体が惜しくなります。
自動判定は主役の色を狙いますが、「この写真で見せたいのはこの色」は撮った本人にしか
分かりません。**作品性を自分でコントロールできる**という点で、価値の大きい要望だと思います。

**実装メモ（設計時に読む）**

現状、写真の色情報は2つに分かれています。

| | 中身 | 使われる場所 |
|---|---|---|
| `dominantColor: Int32?` | 抽出された実際の色（HEX の元） | HEXチップ・パレット・タイルの色ドット |
| `bucketKey: String?` | 12色のどれか（分類） | ハントの絞り込み・カメラの一致判定 |

**⚠️ 今の `rebucket()` は `bucketKey` だけを書き換え、`dominantColor` は触りません**
（`AppState.swift:361`）。つまり「長押しで青→赤に変更」しても、パレットに印字される
HEX は青のままです。**この機能を作るなら、まずここを揃えるべきです。**

推奨する形:

```
ユーザーが HEX を編集
      ↓
dominantColor を更新
      ↓
ColorBridge.shared.classifyKey(colorInt:) で bucketKey を自動で引き直す
```

こうすると「色を選び直す」と「HEXを編集する」が1つの操作に統合され、
2つの値が食い違うことが構造的に無くなります。

**UI の候補**（要検討）
- 写真の長押しメニューに「色を編集」→ カラーピッカー（今日の色のホイールを流用）
- スポイト: 写真の上をドラッグして、その位置の実際のピクセル色を拾う
  ← **これが一番この app らしいと思います。** 「見せたい色」を写真から直接指せる
- HEX の直接入力（`#FF5A3C`）も欲しい人はいる

**効果: 大 / 手間: 中**

## こちらからの提案

### 🔧 A. `.xcodeproj` をリポジトリに入れる

**v1.1 の最初にやるべきです。** いま署名設定・Info.plist の権限文言・アイコンの
割り当ては**あなたの Mac の中にしか存在しません**。Mac が壊れると、ビルドできる状態を
一から作り直すことになります。

**効果: 保険 / 手間: 小**（`IOS_LAUNCH_GUIDE.md` §1 にも記載済み）

### 🔧 B. `rebucket` と `dominantColor` の不整合を直す

上の「1.」の前提になる修正。単体でも意味があります。

**効果: 中 / 手間: 小**

### 🔧 C. Android 版を iOS に追いつかせる

v1.0 の仕上げは iOS 側だけに入っていて、Android は取り残されています。
（下帯の配置・パレットの意匠・コラージュ設定の永続化・カメラの色一致判定）

Android を出す予定があるかどうかで優先度が変わります。**出さないなら、この項目は
落として構いません。**

**効果: Android を出すなら必須 / 手間: 大**

### ✨ D. ホーム画面ウィジェット「今日の色」

WidgetKit で、今日の色をホーム画面に出す。タップでカメラが開く。

**なぜ効くか**: このアプリの弱点は「開く理由が毎日は無い」ことです。ウィジェットは
**開かせるための機能**で、写真アプリの継続率にいちばん効く打ち手です。
今日の色は毎日変わるので、ウィジェットとの相性が非常に良い。

**効果: 大（継続率） / 手間: 中**

### ✨ E. 「今週集めた色」の共有カード

1週間ぶんのハントを、色のグリッド1枚にまとめて共有できるようにする。

**なぜ効くか**: いまの拡散導線はコラージュの透かしだけです。これは「作品を作った人」
しか流してくれません。集めるだけで作れるカードがあると、**コラージュを作らない層も
広告塔になります**。「今週の色」はSNSの定型フォーマットとしても回しやすい。

**効果: 大（拡散） / 手間: 中**

### ✨ F. コレクションの達成率・統計

12色それぞれの収集数、今月の推移、「まだ集めていない色」の提示。

**なぜ効くか**: 「集める」がテーマなのに、いま**集まった実感を返す画面がありません**。
埋まっていく手応えは、この種のアプリの中毒性の芯です。D の「開く理由」とも噛み合います。

**効果: 中〜大 / 手間: 中**

### 💰 N. 英語圏でのブランド衝突を再評価する

**v1.0 では「ColorHunt のまま長い名前で通す」と決めました**（2026-08-04）。

**その理由**（判断の記録・蒸し返さないこと）:

1. カラーハント系の競合は、実際に触った印象として**強くない**
2. それよりも「**SNS で使われる言葉としての馴染みやすさ**」を取る。
   名前がそのままハッシュタグになる設計は既に実装済み（上の N-0）で、
   `#カラーハント` `#色集め` は競合しておらず、自分で育てられる

判断を覆す必要はありませんが、**リリース後に効き目を見る価値があります**。

- App Store には **`ColorHunt - Color Scavenger Hunt`**（ID 1202422081）が既にあり、
  「カメラで色を探す」というコンセプトが近い
- さらに英語の `#colorhunt` は **`colorhunt.co`**（デザイナー向けパレットサイト。
  Instagram `@color.hunt` 6.8万フォロワー）が押さえていて、辿ると写真ではなく
  **パレットの色見本**が並びます
- **どちらも日本語圏には効きません。** `#カラーハント` `#色集め` `#組写` は
  競合しておらず、自分で育てられます。**英語圏の検索とタグでのみ効いてきます**

**見るべき数字**: App Store Connect → 分析 → **検索キーワード経由のインストール**。
英語圏だけ極端に低ければ、これが原因の可能性があります。

**その場合の打ち手**（軽い順）
1. **英語のサブタイトル／キーワードを見直す。** 名前は変えず、`collage` `palette`
   `film` 側で拾う。既に `ColorHunt: Color Collage` と差別化済み
2. **英語ロケールの名前だけ変える。** App Store Connect は言語ごとに別名を付けられます。
   日本語のブランドを保ったまま英語圏だけ差し替えられる
3. 全面改名 ← レビューとランキングを捨てることになるので、最後の手段

> **改名がいちばん安いのは v1.0 提出前でした。** 今後は高くなる一方なので、
> やるなら「数字を見て、早めに」です。

**効果: 英語圏次第 / 手間: 1 は小・2 は中**
