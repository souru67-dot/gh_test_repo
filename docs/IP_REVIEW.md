## 🔴 要判断 — 商標

### A-1. 「チェキ」は富士フイルムの登録商標

**現状**: テンプレート名として **UI に表示** されています。ストア説明文にもあります。

```
"チェキ" = "チェキ"
"チェキの印画紙サイズで固定されています"
"チェキは1枚で仕上がります"
```
> `ja.lproj/Localizable.strings:138,141,166`

**なぜリスクか**: 「チェキ」は富士フイルムの instax シリーズの日本での商品名で、
登録商標です。自社アプリの**機能名**として使うと、商標的使用にあたる可能性があります。
「チェキ風」のように**説明として一度触れる**のと、機能の名前そのものにするのでは
risk が違います。

**起こりうること**: ① Apple の審査で 5.2.1（第三者の商標）に触れる
② 権利者からの申し入れ。どちらも致命傷ではありませんが、時間を取られます。

**選択肢**

| 案 | 内容 | 検索流入 | リスク |
|---|---|---|---|
| 1 | このまま出す | 最大 | 高 |
| 2 | **UI名を「インスタント」に変更、説明文で「チェキ風」と一度だけ記述** | ほぼ維持 | 低 |
| 3 | 完全に排除 | 減る | 最小 |

**推奨は案2**です。日本のユーザーが「チェキ」で検索するのは事実なので、
説明文に記述的に一度だけ残しつつ、機能名からは外すのが折衷案になります。

**作業量**: `Localizable.strings` 4ファイルの文言だけ。**コード変更は不要**です
（テンプレートID `"cheki"` は内部識別子なので、表に出ません）。

### A-2. 韓国語の「폴라로이드」は Polaroid の登録商標 ★A-1より明確

**現状**:

```
"チェキ" = "폴라로이드";
"チェキの印画紙サイズで固定されています" = "폴라로이드 인화지 크기로 고정됩니다";
```
> `ko.lproj/Localizable.strings:138,141,166`

**なぜ A-1 より問題か**: Polaroid 社は商標の権利行使に積極的です。
また韓国語には **「즉석사진」という完全に一般的な語**があり、
代替に困りません。

**しかも、同じアプリの中で表記が割れています。**
ストア説明文（`APP_STORE_LISTING.md`）の韓国語テンプレート一覧では既に
`즉석사진` を使っており、アプリ内だけ `폴라로이드` になっています。

**推奨**: `폴라로이드` → **`즉석사진`** に統一。これは判断というより
**単なる不統一の修正**なので、迷わず変えてよい箇所です。

### A-3. 韓国語キーワードの「인생네컷」はフォトブースのブランド名

**現状**: ストアのキーワードと説明文で使用。

「인생네컷」は韓国のフォトブース事業者の登録商標です。
一般名詞化が進んではいますが、キーワードに入れるのはリスクがあります。

**対応済み**: キーワードからは **`네컷사진`**（一般的な表現）に差し替えました。
説明文の本文にはまだ残っているので、そちらも変えるか判断してください。

## 🟡 検討推奨 — UI の類似

### B-1. グリッド画面が Instagram のプロフィール画面に似ている

**現状**: 円形アバター＋3つの数値＋3列グリッド＋黒背景。

```swift
stat("\(state.gridPhotos.count)", "投稿")
stat("—", "フォロワー")
stat("—", "フォロー中")
```
> `GridPreviewView.swift:48-50`

**法的な評価**: **UIのレイアウト自体は、著作権では保護されにくい**分野です
（アイデア・機能であって表現ではない、とされます）。トレードドレスの主張には
「周知性」と「混同のおそれ」が要りますが、

- Instagram のロゴを使っていない
- プロフィール名は "ColorHunt"
- 配色は自前のブランドカラー
- そもそもフィードプレビュー系アプリ（Preview / UNUM / Planoly など）は
  App Store に多数あり、すべて同じ構造をしています

ため、**混同のおそれは低い**と考えられます。

**それでも気になる点が1つあります。**

「**投稿 / フォロワー / フォロー中**」は Instagram のラベルそのものです。
しかも `フォロワー` と `フォロー中` は **常に「—」しか表示しません**。
つまり**機能的な意味がゼロなのに、他社UIの模倣度だけを上げています**。

**推奨**: この2つを消すか、機能的な表現に変える。

| 現在 | 案 |
|---|---|
| 投稿 / フォロワー / フォロー中 | **枚数 / 色数**（実際に意味のある数字） |

**これは法的リスクの回避というより、アプリの質の問題**でもあります。
中身のない数字が2つ並んでいるより、「12色中7色を収集」のような
自前の指標のほうが、ColorHunt らしくなります。

### B-2. ブランドのグラデーションが Instagram のロゴ配色に近い

```swift
static let gradient = LinearGradient(colors: [purple, pink, amber], …)
```
> `ColorHuntApp.swift:12-15`

紫 → ピンク → 橙 は、Instagram のロゴと同系統の配色です。

**単独ではまったく問題ありません。** この配色は一般的で、独占できるものでは
ありません。実際アプリ全体で使っていて違和感はなく、ブランドとして機能しています。

**気になるのは、グリッド画面でだけ**です。
「Instagram に似たレイアウト」＋「似た配色」＋「同じラベル」が
**1画面に重なる**と、印象が変わります。

**推奨**: グリッド画面のアバター円だけ、グラデーションをやめて単色にする。
B-1 のラベル変更と合わせれば、類似の印象はほぼ消えます。

## 🟢 対応済み

### C-1. ストアキーワードから商標語を削除

英語からは `instax` / `polaroid` を外していたのに、**他言語で入れてしまっていました**。
Apple はキーワード中の第三者商標を積極的に弾きます。

| 言語 | 削除 | 置き換え |
|---|---|---|
| 日本語 | `チェキ`, `インスタ` | `インスタント`, `正方形` |
| 한국어 | `인생네컷`, `인스타` | `네컷사진`, `인스턴트` |
| 简体中文 | `ins风`, `拍立得` | `海报`, `即时成像` |

### C-2. ストア説明文から "Instagram" の記述を削除

```
変更前: Instagram風のプロフィール表示で、投稿の並びを事前に確認できます。
変更後: SNSのプロフィール風の表示で、投稿の並びを事前に確認できます。

変更前: Preview how your posts will line up, Instagram-style, before you post.
変更後: Preview how your posts will line up in a 3-up feed before you post.
```

ストア説明文での他社商標への言及は、Apple 5.2.1 で指摘されることがあります。

## ⚪️ 確認して問題なかったもの

| 項目 | 確認結果 |
|---|---|
| **アプリ内の "Instagram" 表記** | **1件もありません**（コードコメントに1箇所あるのみ。バイナリには含まれません） |
| **フォント** | カスタムフォントの同梱は**ゼロ**。システムフォントのみ使用のため、フォントライセンスの問題なし |
| **SF Symbols** | Apple のライセンス上、Apple プラットフォームのアプリ内での使用は許諾されています。改変しないこと |
| **アプリアイコン** | 色相環＋ビューファインダーの隅。ありふれた構成要素で、特定の他社アイコンに似ていません |
| **一般名詞のテンプレート名** | `Y2K` `デイログ` `フォトダンプ` `マガジン` `ハーフ` `シームレス` `組写` `ホワイト` `フィルム` `4カット` — いずれも一般的な表現で問題なし |
| **コードコメントの `setlog` / `dazz`** | コメントはバイナリに含まれず、ユーザーの目に触れません。ただし**リポジトリを公開する場合は見えます** |
| **地図** | Apple MapKit を規定どおり使用。OSM のタイル利用は Android 版のみで、帰属表示も実装済み |
