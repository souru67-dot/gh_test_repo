# Play データセーフティ 回答ドラフト

Play Console の「データセーフティ」フォームにそのまま入力できる回答です。
こよみは自前のデータ収集・送信を一切行わないため、回答はシンプルです。

## データ収集・共有の有無

| 質問 | 回答 |
|---|---|
| アプリはユーザーデータを収集または共有しますか? | **いいえ**(端末外への収集・送信・共有を行いません) |
| 収集データを第三者と共有していますか? | いいえ |
| データは転送時に暗号化されますか? | 該当なし(データを送信しません) |
| ユーザーはデータの削除をリクエストできますか? | 該当なし(こよみはサーバーにデータを保持しません。端末内の設定はアプリのデータ削除で消去できます) |

補足:こよみは端末のカレンダー(カレンダープロバイダー)を読み書きしますが、
これは端末内での処理であり、Play の「データ収集」(=アプリの外部へ送信/回収
すること)には該当しません。同期は Android とユーザーが設定済みのアカウント
提供者が行います。

## 「データの種類」セクション

いずれも **収集しない(Not collected)** を選択します。

- 位置情報: 収集しない
- 個人情報(氏名・メール等): 収集しない
- 財務情報: 収集しない
- 連絡先: 収集しない
- カレンダー: **収集しない**(端末上でのみ読み書き。外部送信なし)
- アプリのアクティビティ / 診断情報: 収集しない(解析・クラッシュ SDK なし)

## セキュリティの取り組み(任意記入欄がある場合)

- アプリ独自のネットワーク送信は行いません。
- 第三者の解析・広告・トラッキング SDK を含みません。
- 権限はカレンダー(中核機能)と通知(リマインダー)のみです。

## 広告 ID

使用しません(広告なし)。`AD_ID` 権限は宣言していません。
