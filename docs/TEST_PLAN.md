## 2. 手動QAチェックリスト（リリース前に全項目）

推奨環境: 実機2台以上（API 26〜28 の低スペック機 ＋ API 34/35 の最新機）、
言語 ja/en 両方、ライト/ダークテーマ両方。

### 2.1 ハント（仕分け）
- [ ] 「写真を選ぶ」→ Photo Picker 複数選択 → サムネイルが即時表示され、順次色分類される
- [ ] 「自動で仕分け」→ 権限ダイアログ → 許可で直近200枚が取り込まれる（ボタン下に200枚の説明表示）
- [ ] 取り込み直後に上部トーストで「◯枚を追加しました（重複◯枚・読み込めず◯枚）」が出て、3秒で消える
- [ ] 同じ状態でもう一度「自動で仕分け」→ 追加0枚・重複が取り込み枚数と一致する
- [ ] 権限拒否 → クラッシュせず、手動追加が引き続き使える
- [ ] JPEG / HEIC / PNG / スクリーンショットが正しく表示・分類される（黒画像にならない）
- [ ] 色グループが 赤→…→グレー の順で表示、件数バッジが正しい
- [ ] 写真タップ = 選択トグル（枠が付く）／写真**長押し** = 色変更ダイアログ → 選んだ色のグループへ移動
- [ ] 「あなたのカラーホイール」カード: 既定は折りたたみ＋ミニ色見本、タップで展開/収納
- [ ] フィルターチップで単一色に絞り込み、「すべて」で解除
- [ ] ゴミ箱アイコン → 全消去 → 空状態表示
- [ ] 選択中に「コラージュを作成 (n)」FAB → コラージュタブへ遷移し、**戻ってもハントの状態が保持される**

### 2.2 コラージュ
- [ ] ハントで選んだ写真が反映される（「写真が未選択です」誤表示なし）。選択を増減すると追従
- [ ] プレビューがWYSIWYG（保存画像と同じ見た目）。9:16 でも画面を占有しすぎない
- [ ] 「並べ替え」モード: タイル長押し→ドラッグでフローティングサムネイル＋ドロップ先ハイライト→入れ替わる
- [ ] 「位置調整」モード: 写真ドラッグでトリミング窓がパンする（滑らかさ・保存結果への反映）
- [ ] テンプレート: ホワイト（無料）/フィルム/組写/マガジン/シームレス（Pro）をワンタップ適用。並び順・トリミング位置は保持される
- [ ] レイアウト: グリッド/縦並び/2列の切替
- [ ] パレット配置（Pro）: なし/中央/重ねる/左/右。「重ねる」は半透明で写真に溶け込み、HEXが読める
- [ ] HEXチップ（Pro）: 各写真の左下に色ドット＋HEXのピル。小さいセルでは自動非表示
- [ ] 枚数プリセット 3/4/6/9/カスタム。無料時は上限が掛かる（Pro誘導）
- [ ] SNSサイズ 1:1 / 4:5 / 9:16（無料）、16:9（Pro・ロック表示）
- [ ] 余白/角丸/枠線スライダー、枠線色/背景色スウォッチ、テーマ色スイッチ
- [ ] 色相で自動整列
- [ ] 保存 → ギャラリーに書き出し（API 28 以下は権限フロー）。解像度がSNSサイズ準拠
- [ ] 共有 → シェアシートに画像が渡る
- [ ] 無料時: 書き出しに透かし、Pro後: 透かしなし
- [ ] Paywall: 購入ボタン（Play接続）、デバッグビルドのみ「DEBUG: Proを有効化」表示

### 2.3 今日の色
- [ ] リング型ホイール: タップ/ドラッグで色相選択、中央に選択色、選択後に色＋バケツ名＋HEX表示
- [ ] 「今日の色を自動で」: 複数回転→減速停止のスピン。**連打しても壊れず、毎回違う色に着地しうる**
- [ ] 「この色をハントする」→ ハントタブへ
- [ ] 毎日の通知トグル: API 33+ は通知権限フロー → 翌日通知が届く（時刻はWorkManagerの制約内）

### 2.4 グリッド
- [ ] 「写真を追加」/FABで Photo Picker から独自に選択（ハントの選択とは独立）
- [ ] 4:5 セルのInstagram風フィード、プロフィール数値=1
- [ ] 長押しドラッグで並べ替え、×バッジで削除、空状態から再選択

### 2.5 マップ
- [ ] 位置情報付き写真がピン表示（ドミナントカラーの丸）
- [ ] ピンをタップ → **写真サムネイル＋色名＋HEXの吹き出し**（空の吹き出しにならない）
- [ ] 「写真を選ぶ」経由の画像: 写真権限ありならGPS復元されピンが立つ／権限なしは「位置情報なし」欄へ（仕様）
- [ ] 色チップでフィルター
- [ ] 散歩ログ書き出し → 保存＆共有
- [ ] 位置情報付き写真ゼロ時の空状態

- [ ] 200枚取り込み時のスクロール・メモリ（OOMなし）
- [ ] ja/en 表示崩れなし、ダークテーマで視認性OK

## 4. 既知の制限（v1.0 仕様として明記）

1. **データはインメモリ** — アプリ終了で写真リスト・選択・コラージュ設定は消える（写真本体は消えない）。v1.1でRoom/DataStoreによる永続化を計画
2. Photo Picker 経由の画像は、写真権限が無い場合OSの仕様で位置情報を取得できない
3. 彩度20%未満は白/黒/グレーに分類（くすんだ色は色名が付かない）— 誤爆防止のための意図的仕様
