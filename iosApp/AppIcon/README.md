# ColorHunt アプリアイコン

`icon.svg` がマスターソースです（1024×1024・フルブリード正方形）。

**デザイン意図**: アプリの核である「12色のカラーコレクション」を、カメラの
絞りリングに見立てたヒューリングで表現。中央の白いドットは「今日の色に
フォーカスする」ハントの瞬間。ダーク基調 `#101014` はアプリ UI と同一で、
ホーム画面でも一目で ColorHunt と分かる高彩度シグネチャです。

> 角丸は付けないこと（iOS が自動でスクワークルにマスクします）。

## PNG への書き出し（1024×1024）

いずれかの方法で:

- **Figma / Sketch**: icon.svg をインポート → 1024×1024 PNG でエクスポート
- **macOS CLI**:
  ```bash
  brew install librsvg
  rsvg-convert -w 1024 -h 1024 icon.svg -o icon-1024.png
  ```
- オンライン変換（CloudConvert 等）でも可

## Xcode への設定

1. `Assets.xcassets` → `AppIcon` を開く
2. **iOS 1024pt (Single Size)** スロットに `icon-1024.png` をドロップ
   （Xcode 14+ は 1024 一枚で全サイズ自動生成）
3. ビルドしてホーム画面で視認性を確認（明・暗の壁紙両方で）

## バリエーション（App Store 用・任意）

- ダーク/ティンテッドアイコン（iOS 18+）: 背景を透過し、リングを白の
  モノトーンにした版を `AppIcon` の Dark / Tinted スロットへ
- マーケティング用キービジュアルにも同じリングモチーフを流用すると
  ストア掲載の統一感が出ます
